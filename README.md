# 🛒 Amazon E-Commerce Sales & Revenue Analytics (SQL)

## 📌 Project Overview
An exploratory data analysis project evaluating 100,000+ transactional sales records from Amazon. The objective is to identify top-performing product categories, analyze revenue drivers, evaluate fulfillment efficiency, and segment business (B2B) versus retail consumer demand.

## 🛠️ Tech Stack & Skills
* **Language & Database:** SQL (PostgreSQL / SQLite / MySQL)
* **Core SQL Concepts:** Data Aggregations (`SUM`, `AVG`, `COUNT`), Grouping & Filtering (`GROUP BY`, `HAVING`), Conditional Segmentation (`CASE WHEN`), Null Handling (`COALESCE`), Data Type Casting, Sorting & Limits (`ORDER BY`, `LIMIT`).

## 🔍 Key Analytical Queries
* **Financial Overview:** Calculated total gross revenue, transaction counts, and average order value (AOV).
* **Category & SKU Performance:** Ranked top-selling product categories and identified the top 5 revenue-generating SKUs.
* **Customer Segmentation:** Quantified volume, quantity, and gross sales differences between B2B and retail consumer orders.
* **Logistics & Fulfillment:** Mapped delivery status against fulfillment channels to track fulfillment distribution.
